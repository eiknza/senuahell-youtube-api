# SenuaHell YouTube API

Render Web Service ayarları:
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`

Environment Variables:
- `YOUTUBE_API_KEY`: Google Cloud'dan oluşturulan YouTube Data API v3 anahtarı
- `YOUTUBE_CHANNEL_HANDLE`: Kanal kullanıcı adı, `senuahellx` gibi `@` olmadan

Test: `https://SERVIS-ADRESIN.onrender.com/health` ve `https://SERVIS-ADRESIN.onrender.com/api/youtube/videos`

API anahtarını bu depoya veya site dosyalarına EKLEME. Yalnızca Render Environment bölümüne ekle.
